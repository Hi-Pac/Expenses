# تطبيق مصروفي (Masroufy) - لإدارة الميزانية والمصاريف الشخصية 🚀

تطبيق ويب تقدمي (PWA) متجاوب باللغة العربية، يعمل على الكمبيوتر والهاتف المحمول (Android و iOS) مع المزامنة السحابية عبر **Supabase**.

---

## 🌟 مميزات التطبيق

1. **لوحة تحكم مالية شاملة (Dashboard):**
   - مؤشرات الدخل، الأقساط، المصاريف، صافي السيولة، ونسبة الادخار.
   - **حد الصرف اليومي الآمن (Safe Daily Spend):** يحسب لك تلقائياً كم يمكنك أن تصرف يومياً حتى نهاية الشهر دون عجز.
   - **مراقبة الميزانية مقابل الفعلي:** أشرطة تقدم ملونة وتنبيهات فورية باللون الأحمر عند تجاوز ميزانية أي فئة.
   - **رادار تنبيهات الأقساط:** تنبيه بالالتزامات المتأخرة وتلك التي تستحق خلال 3 أيام.

2. **سجل المصاريف الذكي (Quick Expenses):**
   - زر عائم (+) على الهاتف لتسجيل المصروف في 3 ثوانٍ.
   - **الإدخال الذكي باللغة الطبيعية:** كتابة مثل `"250 بنزين كاش"` وسيقوم التطبيق بتعبئة البيانات وتصنيفها تلقائياً.

3. **الأقساط والجمعيات الشهرية (Commitments):**
   - عداد لمواعيد الاستحقاق.
   - زر سريع للتبديل بين "معلق" و "تم السداد".

4. **المزامنة السحابية (Supabase Sync) + دعم وضع عدم الاتصال (Offline-First):**
   - يعمل التطبيق تلقائياً حتى بدون إنترنت على جهازك ويحفظ البيانات محلياً.
   - بمجرد إدخال مفاتيح Supabase، يزامن البيانات لحظياً بين الكمبيوتر وجميع الهواتف.

---

## 🛠️ خطوات التشغيل المحلي

### 1. التشغيل السريع:
اضغط ضغطتين على ملف:
`تشغيل_التطبيق.bat`

### 2. الروابط:
* **من جهاز الكمبيوتر:** `http://localhost:5173`
* **من الهاتف المحمول (نفس شبكة الواي فاي):** `http://192.168.1.8:5173`

---

## ☁️ خطوات الربط مع Supabase (خلال دقيقة واحدة)

1. أنشئ حساباً مجانياً على [Supabase.com](https://supabase.com) وأنشئ مشروعاً جديداً (New Project).
2. من القائمة الجانبية في Supabase، افتح **SQL Editor**.
3. افتح ملف `supabase_schema.sql` الموجود داخل مجلد المشروع، وانسخ كل محتواه والصقه في الـ SQL Editor واضغط **RUN**.
4. اذهب إلى **Project Settings > API** وانسخ:
   - **Project URL**
   - **Project API Key (anon/public)**
5. افتح التطبيق، واذهب إلى تبويب **الإعدادات والسحابة** والصق الرابط والمفتاح واضغط **حفظ واختبار الاتصال**.

---

## 📱 التثبيت كتطبيق على الموبايل (PWA)

* **أندرويد (Chrome):** اضغط على قائمة المتصفح (⋮) ⬅ **إضافة إلى الشاشة الرئيسية (Install app / Add to Home screen)**.
* **آيفون (Safari):** اضغط على زر المشاركة ⬅ **Add to Home Screen**.
